## 📋 Sobre o Projeto

Sistema web desenvolvido para centralizar e facilitar o acesso aos materiais didáticos das disciplinas de Desenvolvimento Web ministradas pelo Prof. Lucas Sousa na FIAP. A plataforma oferece uma interface intuitiva e moderna para navegação entre aulas, materiais complementares e recursos educacionais.

### ✨ Características Principais

- 🎨 **Interface Moderna**: Design responsivo com as cores oficiais da FIAP
- 📱 **Totalmente Responsivo**: Funciona perfeitamente em desktop, tablet e mobile
- 🎯 **Navegação Intuitiva**: Acesso rápido por disciplina e semestre
- 📖 **Materiais Organizados**: Slides, PDFs, códigos e pastas estruturadas
- 🔄 **Dropdown Animado**: Transições suaves ao expandir/recolher conteúdo
- 📚 **Biblioteca de Livros**: Carrossel automático com livros recomendados
- 🔗 **Links Diretos**: Acesso direto ao repositório GitHub para cada material

## 🎓 Disciplinas Disponíveis

### 1. Front-end Design

- Fundamentos de HTML5 e CSS3
- Layouts Responsivos (Flexbox e Grid)
- Frameworks CSS (Bootstrap, Tailwind)
- Prototipagem e Design de Interfaces
- Animações e Transições

### 2. Web Development with JS

- JavaScript Fundamentals
- DOM Manipulation
- Programação Assíncrona
- React e Node.js
- APIs REST e Fetch

### 3. Low Code Development

- Plataformas Low-Code
- Desenvolvimento Rápido
- Automação de Processos

## 🎨 Funcionalidades Detalhadas

### Banner Hero

- Degradê nas cores oficiais da FIAP (#E4097D → #C8056B → #A0044F)
- Logo animada com efeito hover
- Links para redes sociais (GitHub e LinkedIn)
- Cards de estatísticas com ícones e animações
- Padrão decorativo de pontos no background

### Sistema de Abas

- Navegação entre disciplinas
- Seleção de semestre (1º e 2º)
- Transição suave entre conteúdos

### Cards de Aulas

- Expansão suave com animação CSS
- Diferentes estilos para:
  - Aulas regulares
  - Checkpoints
  - Global Solutions
  - Exames
- Links diretos para materiais no GitHub

### Carrossel de Livros

- Scroll automático infinito
- Imagens dos livros recomendados
- Fallback para imagens não encontradas

### Materiais Extras

- Seção destacada com livros e recursos
- Link direto para pasta de extras no GitHub
